# Контракт данных FC 27

Адаптер проверен на публичном интерфейсе FUTBIN 2026-10-29. Это версионируемый контракт HTML; изменение сайта требует новых примеров и проверки парсера.

## Идентичность

`CardKey = (Season, FutbinId)`, `MarketKey = (CardKey, Platform)`.

FUTBIN ID берётся непосредственно из `/27/player/{id}/{slug}`. EA base-player ID, имя, рейтинг и название промо не используются для объединения. Slug может меняться без смены ключа. Перед анализом проверяются запрошенный и конечный URL и canonical, если он есть. Все ключи сохраняются до JSONL, Redis и Telegram.

Проверенный пример Michael Olise: Normal `62`, TOTW `22947`, HoloTOTW `22948`, BundesPOTM SBC `23101`. Последний может показывать положительную **стоимость SBC**; это не цена продажи карточки. ID относятся именно к сезону 27 и не переносятся в другие сезоны.

## Извлечение

| Значение | Наблюдаемый источник |
|---|---|
| Каталог | `/27/players?eUnt=1&player_rating=80-99&page=N` |
| Применённый фильтр | `.selected-filters-wrapper`, текст `Exclude untradeables` |
| Карточка | `.players-table tbody tr`, ссылка `.table-player-name` |
| Рейтинг / версия / позиция | `.table-rating`, `.table-player-revision`, `.table-pos` |
| Стоимость SBC | `.table-price-sbc`, `img.sbc` внутри ценовой ячейки |
| Рынок | `/27/player/{futbinId}/{slug}/market` |
| Платформы | `.platform-ps-only` / `.platform-pc-only` |
| Пять цен | `.price-box-original-player .lowest-price-1`, четыре `.lowest-price` |
| Возраст цены | `.prices-updated` |
| Аукционы | `.auctions-table-box .auctions-table tbody tr` |
| Колонки аукциона | дата, выставлено, продано, налог, net, тип |
| Результат | `.positive-color` (продан), `.negative-color` (не продан) в ячейке даты |
| Тип продажи | текст `Buy Now` / `Bid` в последней ячейке |

Пустая/нулевая цена сохраняется как `null` на своей позиции. Пять чисел не восстанавливаются копированием второй цены. Неизвестная история не равна пустому успешному ответу. Некорректная строка истории запрещает сигнал по снимку.

Даты в DOM без года. Браузер задаёт locale en-GB и Europe/London, парсер переводит даты в UTC, учитывает границу года и отклоняет неоднозначный/несуществующий час DST. Возраст цены и даты имеют округление до минуты; для доказательства продаж после котировки оставлен минутный запас.

Старая схема `/24/playerPrices?player={EA-resource-id}` и `/24/getPlayerSales` больше не используется. Не следует подставлять FUTBIN ID вместо EA resource ID в старый JSON endpoint. В новом адаптере дополнительное сопоставление EA ID не нужно.

## Ликвидность и оценка

На каждом снимке выбираются завершённые аукционы за последние W минут:

- `observedBuyNowPerHour = successfulBuyNowCount × 60 / W`;
- `observedSellThrough = soldCount / endedCount`, где soldCount включает завершённые Bid и Buy Now;
- последнее время Buy Now, количество Buy Now после котировки;
- цены Buy Now используются для медианы, MAD и сравнения ранней/поздней частей окна. Bid не оценивает цену мгновенной продажи.

Оценка будущей продажи ограничивается и выполненными покупками, и текущими альтернативными предложениями. Из выручки вычитаются конфигурируемая комиссия (исходно 5%) и резерв (2%), затем сравниваются абсолютная прибыль и ROI.

История ограничена теми строками, которые FUTBIN показал на странице. Нет гарантии полноты или равномерной выборки. Поэтому скорость — **наблюдаемая активность**, доля проданных — **доля в выборке**, не вероятность продажи нашей карточки. Время до продажи и полный объём рынка не прогнозируются.

Снимки хранятся отдельно. Нельзя склеивать аукционы по `(время, цена)`: сайт не даёт ID сделки, а дата округлена. При будущей калибровке использовать временное разделение train/validation и отдельные сегменты по платформе/ценовому диапазону. Без собственных фактов покупки/продажи JSONL позволяет проверять устойчивость цены и качество фильтров, но не доказать фактическую прибыль или возможность исполнить сигнал.

## Ошибки и доставка

- `SourceFormatException`: нарушен ожидаемый контракт, текущий цикл прекращается.
- HTTP 403/429: цикл прекращается, весь пул ждёт `max(BlockCooldownSeconds, Retry-After)`.
- HTTP 5xx: ограниченное количество повторов с увеличением задержки; никаких повторов через другой прокси ради обхода блокировки.
- Ошибки конкретного уведомления/хранилища: карточка отмечается ошибкой, остальные продолжают обработку; проход становится degraded.
- Атомарный Redis `SET NX` + TTL; освобождение при ошибке через Lua compare-and-delete. Точно-однократная доставка в Telegram не гарантируется при неоднозначном результате сетевого запроса.

## Что изменено относительно старой версии

Заменены маршруты и зависимость от EA resource ID; прежний FUTBIN ID расширен до ключа с сезоном и платформой. Убраны фильтр каталога по текущей цене и специальное исключение IF. Исправлены копирование второй цены в позиции 3–5, `async void` внутри `Parallel.ForEach`, общая изменяемая история между запросами, анализ без временного окна и гонка check-then-set в Redis. Исключено отключение проверки TLS. Картинка из старых шаблонов заменена текстовым сигналом с точной ссылкой на карточку, чтобы сбой отрисовки не мешал доставке.
